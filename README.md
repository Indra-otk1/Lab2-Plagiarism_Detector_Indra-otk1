Plagiarism Analyzer & Text Comparison Tool

This project provides a simple command-line Python utility for comparing two text files (essays/essay1.txt and essays/essay2.txt) to determine their textual similarity. The core functionality involves cleaning the input text by converting it to lowercase, removing punctuation, and filtering out common English stop words. Once cleaned, the script calculates the similarity score using the Jaccard Index, which compares the ratio of common unique words to the total unique words across both documents. Additionally, the tool offers an interactive feature to search for the frequency of a user-specified word in both essays and identifies all unique words shared between the two files. The final analysis, including the similarity score and common words, can optionally be saved to a report file in the reports/ directory.

To get started, first execute the included setup script, setup.sh (./setup.sh), which creates the necessary essays/ and reports/ folders. Next, place your two documents as essay1.txt and essay2.txt inside the essays/ directory. Finally, run the main analyzer using the command python3 essay_analyzer.py. The program will guide you through a brief interactive session and display the results immediately upon completion.
